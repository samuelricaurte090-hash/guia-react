# Empleo

Aquí va todo lo que sirve para postular: las vacantes que revises, tu CV y las notas de cada entrevista.

## vacantes.csv

En la semana 3 anota 20 vacantes remotas junior de desarrollo web, una por fila. Sirven para saber qué pide de verdad el mercado (qué stack, cuánto inglés, cuánta experiencia) y ajustar lo que estudias.

| Columna | Qué escribir | Ejemplo |
|---|---|---|
| fecha | Día en que la viste | 2026-11-03 |
| empresa | Nombre de la empresa | |
| cargo | Título exacto de la vacante | Frontend Developer Junior |
| pais_empresa | País de la empresa | Colombia |
| modalidad | Remoto, híbrido o presencial | Remoto |
| salario | Solo el número, vacío si no lo dicen | 3500000 |
| moneda | COP, USD, EUR... | COP |
| experiencia_anios | Años que piden, 0 si no piden | 1 |
| ingles | Nivel que piden, vacío si no piden | B1 |
| stack | Tecnologías separadas por barra vertical | React\|TypeScript\|Node\|PostgreSQL |
| enlace | URL de la vacante | |

## Dónde buscar

Con inglés básico, empieza por empresas que trabajan en español:

- [Get on Board](https://www.getonbrd.com/): empresas de tecnología de Latinoamérica, con muchas vacantes remotas y el salario publicado.
- [LinkedIn Empleos](https://www.linkedin.com/jobs/): filtra por "En remoto" y por nivel "Sin experiencia" o "Junior".
- [Torre](https://torre.ai/): trabajo remoto, con perfil por habilidades.
- Computrabajo, elempleo.com y Magneto Empleos, con el filtro de teletrabajo.

Desconfía de cualquier oferta que te pida pagar por un curso, por equipos o por "asegurar el cupo".
